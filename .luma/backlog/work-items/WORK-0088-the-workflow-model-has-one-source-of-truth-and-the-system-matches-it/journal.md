## ▶ 2026-09-10

written as OUTCOMES rather than a plan, on the maintainer's instruction — say where we want to be when it is done, not what to do. the how is prepared together, after review
REALIGNMENT that produced this: unprepared is a RESTING PLACE and is not in question. work is selected for preparation and sits there until somebody has capacity, and a populated rung is the design working. an agent churned it, the maintainer moved everything back to captured to clean up, and the agent then read the empty rung as evidence about the design — inverting cause and effect
and the model is a WALK, not a leap: asking for a distant rung is asking to be taken through the ladder quickly, not around it. every rung's rules apply as it passes; fast-tracking changes how long is spent at each, never how many are answered. breaking protocol is a separate act, allowed, tracked and visible
which means there is no table of 42 moves — there is one row per rung, forward, and the existing 'what each rung asks for' table was already the right shape. what it was missing was the sentence saying its rows fire for every rung TRAVERSED rather than only at the two ends
CONCEPTUAL FRAMING worth keeping, from the session that produced this record: a gate is where an OBLIGATION IS TAKEN ON. above the first, nobody owes the record anything and it can sit forever with nothing wrong. below it somebody owes it understanding; below the second, somebody owes it doing
which explains why gates feel different in kind from the rungs between them — the rungs are progress, the gates are promises — and why the checks at a gate are bookkeeping hanging off the promise rather than the point of it. useful when writing the source of truth
