# Accept a positional title on work-item new

`work-item new <title>` and `work-item new --title <title>` both work;
**supplying both is an error** rather than one silently winning.

The positional is what a person types; the flag is what survives being
generated by something else.

**Verified by:** each form alone creates the record; both together exit 2
naming the conflict; creation stays idempotent by name (§9.5).
